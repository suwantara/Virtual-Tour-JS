# Halaman Auth

## Login (`/login`)

| Elemen | Teks |
|---|---|
| `<title>` halaman | `Log in` |
| Judul form | `Log in to your account` |
| Deskripsi form | `Enter your email and password below to log in` |
| Label field email | `Email address` |
| Placeholder field email | `email@example.com` |
| Label field password | `Password` |
| Placeholder field password | `Password` |
| Link lupa password | `Forgot your password?` |
| Label checkbox | `Remember me` |
| Tombol submit | `Log in` |

---

## Lupa Password (`/forgot-password`)

| Elemen | Teks |
|---|---|
| `<title>` halaman | `Forgot password` |
| Judul form | `Forgot password` |
| Deskripsi form | `Enter your email to receive a password reset link` |
| Label field email | `Email address` |
| Placeholder field email | `email@example.com` |
| Tombol submit | `Email password reset link` |
| Teks bawah | `Or, return to` |
| Link kembali | `log in` |

---

> **Catatan:** Halaman `/register` dinonaktifkan secara sengaja — registrasi publik tidak tersedia (sesuai SRS 18.6).
> User baru hanya dapat dibuat melalui admin panel Filament.
